# version-001 剪辑说明

## 总体设计

这一版是 15 秒横版 MVP，用 HyperFrames HTML composition 表达剪辑结果。因为第一阶段不接真实素材，画面中间使用“主视频占位区域”模拟口播人物，所有字幕、大字和装饰元素都避开中间人物安全区。

## 分段说明

### 0:00-0:03
- 字幕：这个视频开头所有的剪辑和动画效果，都是 AI 完成的。
- 大字：`AI 自动完成剪辑`。
- 设计原因：开头直接给出最大利益点，建立“AI 自动剪辑”的钩子。
- 动画：大字从下方轻入场，背景主画面轻微推近。

### 0:03-0:06
- 字幕：我只需要给它原始素材，再用自然语言告诉它需求。
- 屏幕元素：左下方出现 `素材 + 需求 + 字幕` 提示胶囊。
- 设计原因：把输入条件用一个简洁标签说明清楚，不遮挡人物。

### 0:06-0:09
- 字幕：这一期我们就实操看看，AI 后期到底怎么做。
- 设计原因：承接前两句，从概念切换到实操预期。
- 动画：保持轻微推拉，不做强转场，保证口播可读性。

### 0:09-0:12
- 字幕：最关键的是，一定要给它带时间戳的字幕。
- 大字：`关键：时间戳字幕`。
- 设计原因：突出 MVP 的核心输入条件，后续自动剪辑计划也依赖这个信息。

### 0:12-0:15
- 字幕：这样它才能知道什么时候该加什么效果。
- 屏幕元素：只保留少量点状装饰，降低视觉负担。
- 设计原因：收束信息，让观众理解“时间戳 → 效果时机”的因果关系。

## 字幕和大字对应

- 第 1 条字幕对应开头强钩子大字：`AI 自动完成剪辑`。
- 第 4 条字幕对应关键机制大字：`关键：时间戳字幕`。
- 其他字幕只保留底部显示，避免屏幕元素过多。

## 当前占位内容

- `assets/raw/main.mp4` 尚未放入真实口播素材，composition 使用 CSS 生成的口播人物占位。
- overlays 只是占位图形，后续可以替换为真实截图、图标、产品界面或强调框。
- 剪辑计划目前是规则生成，不调用真实 LLM；后续可读取 `prompts/edit-request.md` 做语义分析。
